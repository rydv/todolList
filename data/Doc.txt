Example Usage for Each Identifier
1. |EXACT|<exact value>
Rule: RULE001
Filter 1 Value: |EXACT|FX
Filter 2 Value: |EXACT|MX
Explanation:

Filter 1 matches any transaction containing the exact string "FX".
Filter 2 matches any transaction containing the exact string "MX".
Example Transaction:

Filter 1 Match: FX123456789
Filter 2 Match: MX987654321
These transactions are considered valid matches for RULE001 if both exact values are present.

2. |EXP|<expression>
Rule: RULE002
Filter 1 Value: |EXP|\d{9}
Filter 2 Value: |EXP|\d{9}
Explanation:

Filter 1 matches any transaction containing a sequence of 9 digits.
Filter 2 matches any transaction containing a sequence of 9 digits.
Example Transaction:

Filter 1 Match: Transaction with 123456789
Filter 2 Match: Transaction with 987654321
These transactions are considered valid matches for RULE002 if both expressions match a sequence of 9 digits.

3. |EXP|(<expression>)
Rule: RULE003
Filter 1 Value: |EXP|(\d{9})
Filter 2 Value: |EXP|(\d{9})
Explanation:

Filter 1 captures the matched value from the expression (a sequence of 9 digits).
Filter 2 captures the matched value from the expression (a sequence of 9 digits).
The captured values from Filter 1 and Filter 2 are compared.
Example Transaction:

Filter 1 Match: Transaction with 123456789
Filter 2 Match: Transaction with 123456789
These transactions are considered valid matches for RULE003 if the captured values from both filters are identical.

4. |DT_FRMT|<date format>
Rule: RULE004
Filter 1 Value: |EXP|(\d{8})|DT_FRMT|DDMMYYYY
Filter 2 Value: |EXP|(\d{4}-\d{2}-\d{2})
Explanation:

Filter 1 captures a date in the format DDMMYYYY.
Filter 2 captures a date in the format YYYY-MM-DD.
The captured dates are compared after conversion to a common format.
Example Transaction:

Filter 1 Match: Transaction date 25122018
Filter 2 Match: Transaction date 2018-12-25
These transactions are considered valid matches for RULE004 if the captured dates are equivalent after format conversion.

5. |OP|<operation details>
Rule: RULE005
Filter 1 Value: |EXACT|ATM WDR AT 2164 MDS |EXP|(\d{2}:\d{2}:\d{2})|OP|REP|:||
Filter 2 Value: |EXP|(\d{6})
Explanation:

Filter 1 matches transactions with text ATM WDR AT 2164 MDS followed by a time in HH:MM
format.
The operation REP|:|| replaces colons : in the time with an empty string.
Filter 2 matches the transformed time format HHMMSS.
Example Transaction:

Filter 1 Match: ATM WDR AT 2164 MDS 13:46:43
Filter 2 Match: 134643
These transactions are considered valid matches for RULE005 if the transformed time from Filter 1 matches the value in Filter 2.
